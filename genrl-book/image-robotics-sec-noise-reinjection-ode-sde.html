26. 이미지·로보틱스의 강화학습: GRPO가 시각 생성을 만났을 때

노이즈 재주입(ODE → SDE): 결정론적 샘플러에 탐색을 되돌린다

DDPO는 스텝마다 노이즈가 섞이는 확률적 샘플러를 전제했는데, 스텝이 정규분포여야 로그확률이 있고 노이즈가 있어야 탐색이 있기 때문이다. 그런데 FLUX, Stable Diffusion 3 같은 최신 모델은 플로우 매칭(flow matching, rectified flow)으로 학습되어 결정론적 ODE(상미분방정식. 시작점이 정해지면 경로가 하나로 정해진다)로 샘플링하므로 스텝 노이즈가 없어서, 같은 시작 노이즈에서 G장을 뽑으면 G장이 똑같이 나온다.

역사: 같은 주변분포를 주는 ODE와 SDE

2021년 양 송(Yang Song) 등은 「Score-Based Generative Modeling through Stochastic Differential Equations」(ICLR 2021)에서 디퓨전을 확률미분방정식(SDE)으로 썼다. 그들은 SDE마다, 모든 시점에서 같은 주변분포(경로 전체가 아니라 한 시점 ttt의 xtx_txt​만 모아 본 분포)를 주는 결정론적 ODE인 확률 플로우 ODE(probability flow ODE)가 하나씩 있음을 보였다. 플로우 매칭은 처음부터 이 ODE의 속도장(각 위치·시점에서 xxx가 움직일 방향과 시간당 움직이는 거리를 정해 주는 함수)을 학습하는 방법이다. 시각 생성 RL은 SDE와 확률 플로우 ODE의 대응을 거꾸로 써서, ODE로 학습된 모델에서 SDE를 만든다.

그림은 같은 시작점 여섯 개를 ODE로 보내면 경로가 매끈하게 하나씩 정해지고, 노이즈를 넣은 SDE로 보내면 경로가 흔들리며 엇갈려도, 점 4000개가 도착한 자리는 두 경우 모두 같은 분포에 모인다는 것을 보여 준다(봉우리가 둘인 장난감 분포에 노이즈 크기 gt=1\textcolor{#993600}{g_t} = 1gt​=1을 넣어 이 책이 직접 계산한 그림).

노이즈를 빼면 ODE고 넣으면 SDE니까, 둘이 같은 분포를 준다는 건 당연한 얘기 아니에요?
점 하나를 따라가 보세요. ODE에서는 시작점이 같으면 경로가 하나죠. SDE에서는요?
음, 같은 시작점에서도 돌릴 때마다 다른 데로 가요. 점 하나만 보면 아예 다른 과정인데요.
그런데 점을 잔뜩 모아 한 시점에서 찍어 보면 모양이 같다는 거네요. 경로는 다른데 주변분포만 같다는 건, 몇 번 돌려 봐서는 확신하기 어려웠겠어요.
그래서 2021년의 대응은 식으로 보인 결과였어요. 그때는 쓰는 방향도 지금과 반대였고요. 디퓨전 모델은 SDE로 학습했고, 짝이 되는 ODE는 노이즈 없이 샘플링하는 데 꺼내 썼어요. ODE의 속도장을 처음부터 학습하는 플로우 매칭은 그다음 해에야 나왔죠.
지금은 거꾸로네요. 가진 건 ODE 모델뿐이고, 그 ODE와 같은 분포를 주는 SDE를 새로 지어야 하는 거죠?
그래요. 노이즈를 넣으면 분포가 퍼질 텐데, 무엇을 함께 넣어야 분포가 그대로일까요?
퍼뜨리고 되모으기: 노이즈를 넣어도 왜 분포가 그대로일까?

해법은 ODE에 노이즈를 더하되, 노이즈가 퍼뜨린 만큼을 되모으는 항을 함께 넣는 것이다. 숫자로 한 스텝만 보자. 어느 시점의 분포가 평균 0, 분산 1인 정규분포이고, 속도장은 잠시 0이라고 하자(점이 스스로 움직이지 않는다). 여기에 분산 0.1짜리 노이즈를 더하기만 하면 분산은 1.1로 퍼지므로, 노이즈를 더하기 전에 모든 점을 분포의 가운데 쪽으로 5%씩 당긴다. 확률이 높은 쪽으로 미는 방향, 곧 스코어 함수(score, 로그 밀도의 그래디언트)의 방향이다. 당기면 분산이 0.952=0.90250.95^2 = 0.90250.952=0.9025로 좁아지고, 노이즈 0.1을 더하면 0.9025+0.1=1.00250.9025 + 0.1 = 1.00250.9025+0.1=1.0025, 거의 처음의 1로 돌아온다. 남는 0.0025는 스텝을 잘게 나눌수록 사라진다(노이즈 분산을 0.01로 줄이면 0.000025). 노이즈는 분포를 퍼뜨리고, 스코어 쪽으로 미는 항은 확률이 높은 곳으로 되모은다. 둘이 맞비기므로 점 하나하나의 경로는 흔들리지만 분포는 평균 0, 분산 1 그대로 유지된다.

문제 2: 복사한 답안 여덟 장의 표준점수

논술 모의고사에서 한 학생이 같은 답안을 여덟 장 복사해 냈다. 채점자는 매번 조금씩 다르게 매겨 7.02, 6.98, 7.01, 6.99, 7.00, 7.03, 6.97, 7.00점을 주었다. (가) 여덟 장의 표준점수(점수에서 평균을 빼고 표준편차로 나눈 값)를 구하시오. (나) 다른 반에서는 여덟 학생이 각자 쓴 답안이 9, 5, 7, 6, 8, 7, 4, 10점을 받았다. 이 반의 표준점수와 비교하면 무엇을 알 수 있는가? (다) 채점자가 여덟 장에 똑같이 7.00점을 주었다면?

평균은 7.00이고 표준편차는 0.0187이에요. 7.03점은 (7.03 − 7.00) / 0.0187 ≈ 1.6, 6.97점은 −1.6. 나머지는 ±1.07, ±0.53, 0, 0이고요.
그럼 이 여덟 장 가운데 가장 잘 쓴 답안은 7.03점짜리인가요?
여덟 장이 전부 같은 답안이라 잘 쓰고 못 쓰고가 없어요. 1.6은 채점자의 손이 조금씩 다르게 간 데서 나온 값이고요.
(나)를 해 보면 더 이상해요. 9, 5, 7, 6, 8, 7, 4, 10은 표준편차가 1.87인데, 표준점수가 ±1.6, ±1.07, ±0.53, 0, 0이에요. 앞 반과 똑같은 숫자 모음이에요.
왜 똑같이 나왔을까요?
두 반 다 평균이 7이니까, 7을 빼고 비교해 볼게요. 앞 반 점수에서 7을 빼고 100배 하면 둘째 반 점수에서 7을 뺀 값들과 같은 모음이 돼요.
그럼 100배 하면 표준편차는 어떻게 되죠?
표준편차도 100배가 되니까, 나누면 몇 배 했는지가 지워져요. 표준점수는 차이가 0.02점이든 2점이든 늘 같은 크기로 맞춰 버려요.
그러면 표준점수만 보고는 채점자의 노이즈인지 진짜 실력 차인지 모르네요.
(다)는요?
표준편차가 0이라 0으로 나누게 돼요. 분모에 아주 작은 수를 더해 두면 표준점수가 전부 0이고요.

정리 (가) 평균 7.00, 표준편차 약 0.019, 표준점수 ±1.6, ±1.07, ±0.53, 0, 0. (나) 실력 차가 나는 반과 표준점수 모음이 똑같다. 표준점수는 차이의 크기를 지우므로, 채점자의 손에서 나온 0.02점 차이도 실력에서 나온 2점 차이와 같은 표준점수(±1.07)가 된다. (다) 표준편차가 0이라 나눌 수 없고, 분모에 작은 수를 더하면 표준점수는 전부 0이다.

문제 3: ODE 그룹의 어드밴티지

플로우 매칭 모델을 ODE로 샘플링하면서 GRPO를 쓰면, 같은 프롬프트·같은 시작 노이즈의 그룹 8개에 대한 어드밴티지(평균보다 얼마나 나은가) A^i=(ri−μ)/σ\textcolor{#8e44ad}{\hat A_i} = (\textcolor{#d9670b}{r_i} - \textcolor{#00897b}{\mu})/\textcolor{#008deb}{\sigma}A^i​=(ri​−μ)/σ는 어떻게 되는가? (μ\textcolor{#00897b}{\mu}μ는 그룹 평균, σ\textcolor{#008deb}{\sigma}σ는 그룹 표준편차)

8개가 전부 같은 이미지니까 보상도 같고, μ=r\textcolor{#00897b}{\mu} = \textcolor{#d9670b}{r}μ=r, σ=0\textcolor{#008deb}{\sigma} = 0σ=0. 어드밴티지는 0/0이에요.
구현에서는 보통 분모에 작은 ε를 더하니까 0/ε = 0. 학습 신호(시그널)가 없어.
문제가 너무 쉬워서 여덟 개가 다 맞은 그룹과 비교하면 어때요?
어드밴티지가 다 0인 건 똑같아요. 그런데 원인이 달라요. 쉬운 문제는 다르게 풀어 봤는데도 다 맞은 거고, 여기는 아예 다르게 풀어 볼 수가 없었어요.
ODE면 시작 노이즈가 같을 때 경로가 하나로 정해지니까요. 스텝 로그확률도 정의가 안 되고요. 그룹이 여덟 개처럼 보여도 사실상 하나예요.
그래요. GRPO에서 "모두 정답이면 배울 게 없다"던 상황이, 문제가 쉬워서가 아니라 샘플러 때문에 생긴 거예요.

정리 모든 보상이 같아 σ=0\textcolor{#008deb}{\sigma} = 0σ=0, 어드밴티지는 (ε를 더한 구현에서) 전부 0이라 학습 시그널이 없다. 보상 모델의 노이즈로 σ\textcolor{#008deb}{\sigma}σ가 0이 아니어도, 경로가 하나라 어드밴티지의 합 0이 곱해져 상쇄된다. 결정론적 샘플러에서는 그룹이 사실상 1개다.
