21. 이미지·영상·로보틱스의 강화학습 — GRPO가 시각 생성을 만났을 때

연습문제와 함께 풀기

문제 1 — 세 갈래 정리

세 갈래(선호 기반, 정책 그래디언트, GRPO 기반) 각각에 대해, 필요한 데이터와 "비평가(가치 모델)가 있는가"를 표로 정리하시오.

세 갈래 중 비평가(가치 모델)가 있는 건 어디일까요?
없어요. DDPO도 비평가 없었고, GRPO는 원래 비평가를 뺀 거고, DPO는 보상도 없으니까요.
정책 그래디언트 갈래가 DDPO 하나만 있는 건 아니잖아. PPO식으로 구현하면 가치 모델을 붙일 수 있어. 로봇 디퓨전 정책을 PPO로 미세조정하는 작업들이 그렇고.
논문 하나를 보고 갈래 전체로 일반화했네요. "보통 없음, PPO식이면 있을 수 있음"이 맞겠어요.
그래요. 그럼 시각 생성에서 비평가가 인기 없는 이유는요?
모델이 커서요. 이미지·영상 모델만 한 비평가를 하나 더 올리면 메모리가 두 배고, 스텝마다 가치를 맞히는 것도 어렵고요.
실험 하나 보고 보고서에 "항상 그렇다"고 썼다가 조교님께 반례를 받은 적이 있어요. 딱 그거네요.

정리 선호 기반: 쌍 데이터, 비평가 없음. 정책 그래디언트: 보상 모델 + 온라인 생성, 비평가는 방법에 따라(DDPO 없음, PPO식은 있음). GRPO 기반: 보상 + 그룹 생성, 비평가 없음(그룹 평균이 대신).

문제 2 — ODE 그룹의 어드밴티지

흐름 매칭 모델을 ODE로 샘플링하면서 GRPO를 쓰면, 같은 프롬프트·같은 시작 노이즈의 그룹 8개에 대한 어드밴티지 A^i=(ri−μ)/σ\hat A_i = (r_i - \mu)/\sigmaA^i​=(ri​−μ)/σ는 어떻게 되는가?

8개가 전부 같은 이미지니까 보상도 같고, μ=r\mu = rμ=r, σ=0\sigma = 0σ=0. 어드밴티지는 0/0이에요.
구현에서는 보통 분모에 작은 ε를 더하니까 0/ε = 0. 학습 시그널이 없어.
그래도 보상 모델이 GPU 비결정성 때문에 소수점 아래 잡음을 조금 내면 σ가 0이 아니니까, 뭔가 배우긴 하겠죠?
민준 학생, 여덟 개가 전부 같은 경로라면 ∇log⁡π\nabla \log \pi∇logπ는 몇 종류죠? 그리고 어드밴티지 여덟 개를 더하면요?
경로가 같으니까 ∇log⁡π\nabla \log \pi∇logπ도 하나뿐이고… 어드밴티지는 평균을 뺐으니 합이 0이에요. 그럼 ∑iA^i∇log⁡π=(∑iA^i)∇log⁡π=0\sum_i \hat A_i \nabla\log\pi = (\sum_i \hat A_i)\nabla\log\pi = 0∑i​A^i​∇logπ=(∑i​A^i​)∇logπ=0.
잡음이 얼마나 부풀려지든 정확히 상쇄되네요. 애초에 ODE면 스텝 로그확률도 정의가 안 되고요.
그래요. Ch16에서 "모두 정답이면 배울 게 없다"던 상황이, 문제가 쉬워서가 아니라 샘플러 때문에 생긴 거예요.
같은 과제를 복사해서 여덟 번 내고, 채점 편차로 어느 게 더 잘 썼는지 따지는 셈이네요.

정리 모든 보상이 같아 σ=0\sigma = 0σ=0, 어드밴티지는 (ε를 더한 구현에서) 전부 0 — 학습 시그널이 없다. 결정론적 샘플러에서는 그룹이 사실상 1개다.

문제 3 — 분기 샘플링의 정체

B²-DiffuRL은 디노이징 중간에서 분기해 여러 완성본을 만들고 보상 차이로 그 스텝의 기여를 추정한다. 이것은 Ch4의 어떤 개념의 몬테카를로 버전인가?

분기해서 여러 장 만들고 보상을 비교하니까 GRPO 그룹이랑 같은 거죠. Ch16이요.
GRPO 그룹은 어디서 갈라지죠? 프롬프트에서요, 디노이징 중간에서요?
프롬프트에서요. 처음부터 따로 뽑죠. 여기는 중간 xtx_txt​에서 갈라지고요.
중간 상태에서 끝까지 여러 번 굴려 평균을 낸 건 "이 상태에서 앞으로 기대되는 보상"이야. 가치 함수 V(xt)V(x_t)V(xt​)의 몬테카를로 추정이고, 같은 분기 안에서 평균보다 나은 정도가 그 구간의 어드밴티지고.
맞아요. GRPO의 그룹 평균은 첫 상태의 가치를 샘플로 잰 거고, 분기 샘플링은 그걸 중간 스텝에서 한 거예요. 비평가를 학습하는 대신 그때그때 굴려서 재는 거죠.
반만 맞았네요. 조교님이 "방법은 맞는데 적용 위치가 틀렸다"며 부분점수 주던 그거요.

정리 중간 상태에서 분기한 롤아웃들의 평균 보상 = 가치 함수 V(xt)V(x_t)V(xt​)의 몬테카를로 추정. 그 차이가 스텝별 어드밴티지다(Ch4의 크레딧 할당).

문제 4 — (킬러) 시작 노이즈를 공유하는 이유

DanceGRPO는 한 그룹의 모든 샘플이 같은 시작 노이즈를 공유하게 한다. 민준은 "탐색이 줄어드니 손해"라고 하고, 서연은 "시작 노이즈까지 다르게 해야 그룹 평균이 프롬프트의 기대 보상을 제대로 추정한다"고 한다. (가) 시작 노이즈가 제각각이면 그룹 내 보상 차이의 출처는 무엇과 무엇인가? (나) 정책 그래디언트는 어느 쪽 차이에서만 배울 수 있는가? (다) 두 학생의 주장을 각각 평가하시오.

(가)부터요. 시작 노이즈가 제각각이면 그룹 내 보상 차이는 어디서 오죠?
두 군데요. 시작 노이즈 xTx_TxT​가 달라서 생기는 차이, 그리고 스텝마다 섞이는 노이즈 — 즉 정책이 고른 행동 — 가 달라서 생기는 차이.
(나) 정책 그래디언트는 둘 중 어느 쪽에서 배우죠? ∇log⁡π\nabla \log \pi∇logπ 가 어디에 붙는지 보세요.
로그확률은 스텝 전이 pθ(xt−1∣xt)p_\theta(x_{t-1} \mid x_t)pθ​(xt−1​∣xt​) 에만 있어요. 시작 노이즈 xTx_TxT​는 그냥 N(0,I)\mathcal{N}(0, I)N(0,I)에서 뽑은 거라 θ가 없어요.
그러면 시작 노이즈 때문에 생긴 보상 차이도 어드밴티지에 섞여 들어가는데, 그 차이를 스텝 행동의 로그확률에 대고 올리고 내리는 거네요. 운이 좋았던 시작점 덕분에 받은 점수를 스텝 행동의 공으로 돌리는 셈이에요.
그럼 (다). 민준 학생은 "탐색이 줄어 손해"라고 했죠.
줄어드는 탐색은 시작 노이즈 쪽인데, 그건 원래 정책이 배울 수 없는 차이였네요. 스텝 노이즈의 탐색은 그대로 남고요. 손해가 아니라 잡음을 뺀 거였어요.
조별과제 점수를 개인 기여로 나눌 때, 조 편성 운으로 생긴 차이까지 개인 점수에 넣으면 안 되는 거랑 같네요. 같은 조 안에서 비교해야 개인 기여가 보이죠.
서연 학생은 "그룹 평균이 기대 보상을 제대로 추정해야 한다"고 했어요. 틀린 말인가요?
틀리진 않은데… 공유하면 그룹 평균은 "이 프롬프트 + 이 시작 노이즈"에서의 기대 보상이 되니까, 추정하는 대상이 좁아지는 거예요. 그런데 어드밴티지는 "같은 조건에서 이 행동이 평균보다 나았나"를 보는 거라, 오히려 조건을 맞춘 쪽이 맞는 베이스라인이네요.
베이스라인은 상태에 조건을 걸수록 분산이 줄잖아요. V(s)V(s)V(s)가 E[R]\mathbb{E}[R]E[R]보다 나은 베이스라인인 것처럼요. 시작 노이즈도 상태의 일부로 본 거네요.
그래요. 서연 학생은 추정 대상을 넓게 잡는 게 좋다고 봤지만, 베이스라인은 같은 상태에서의 기대값일수록 좋아요. 대신 여러 시작 노이즈를 보려면 그룹을 여러 개 만들면 되죠.

정리 (가) 시작 노이즈의 차이 + 스텝 행동의 차이. (나) 로그확률은 스텝 전이에만 있으므로 스텝 행동의 차이에서만 배울 수 있다. 시작 노이즈 차이는 어드밴티지에 섞이는 잡음이다. (다) 민준: 줄어드는 탐색은 원래 배울 수 없는 쪽이라 손해가 아니다. 서연: 그룹 평균의 추정 대상은 좁아지지만, 같은 상태에 조건을 건 베이스라인이 분산이 더 작다(Ch4의 V(s)V(s)V(s)와 같은 논리). 다양한 시작 노이즈는 여러 그룹으로 확보한다.
