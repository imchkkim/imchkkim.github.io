Chapter 9: 길이 편향 — 합이 공정한가?

의문

토큰의 로그확률은 항상 ≤0\le 0≤0이다. Ch8에서 문장 점수는 이것들의 합이라고 했다. 그렇다면 토큰이 많을수록 점수는 마이너스 쪽으로 멀어진다. 길이가 다른 두 응답을 이 점수로 비교하는 것은 공정한가?

같은 두 응답을 세 가지 잣대로 재 보자. 정답 ywy_wyw​는 12토큰이고 토큰마다 확률 0.8로 자신 있게 생성된다. 오답 yly_lyl​은 4토큰이고 토큰마다 확률 0.6이다. 토큰 하나하나로 보면 정답 쪽이 명백히 더 확신에 차 있다.

확률과 로그확률의 합은 같은 순서를 준다(로그는 단조 함수다). 둘 다 길다는 이유만으로 정답을 진다고 판정한다. 곱할 때마다 1보다 작은 수가 붙으니, 아무리 좋은 답이어도 길기만 하면 점수가 바닥으로 간다. 평균으로 나누어야 비로소 토큰당 확신의 차이가 드러난다.

DPO는 어떤 잣대를 쓰는가

DPO의 마진은 로그확률의 합으로 만든다. 다만 원래 로그확률이 아니라 레퍼런스와의 비율 log⁡πθπref\log \frac{\pi_\theta}{\pi_\text{ref}}logπref​πθ​​ 의 합이다. Ch6에서 봤듯 이것이 DPO의 암묵적 보상이다.

rDPO(x,y)=β∑t=1∣y∣log⁡πθ(yt∣x,y<t)πref(yt∣x,y<t)r_\text{DPO}(x, y) = \beta \sum_{t=1}^{|y|} \log \frac{\pi_\theta(y_t \mid x, y_{<t})}{\pi_\text{ref}(y_t \mid x, y_{<t})}rDPO​(x,y)=βt=1∑∣y∣​logπref​(yt​∣x,y<t​)πθ​(yt​∣x,y<t​)​

레퍼런스로 나누기 때문에 위 표 같은 노골적인 편향은 학습 초기에는 없다 — 처음에는 πθ=πref\pi_\theta = \pi_\text{ref}πθ​=πref​ 라 모든 응답의 보상이 0이다. 하지만 합이라는 구조는 그대로 남는다. 학습이 토큰마다 비율을 조금씩 바꾸면, 토큰이 많은 응답일수록 보상이 더 크게 움직인다. 선호 데이터에서 선호 응답이 비선호 응답보다 긴 경향이 있으면(실제 공개 데이터셋에서 흔하다), DPO는 "길게 쓰면 마진이 잘 벌어진다"를 배운다. 결과는 점점 장황해지는 모델이다(연습문제 4). Park et al.(2024)은 이 현상을 측정하고, 마진에 길이 차이 벌점을 넣는 R-DPO를 제안했다.

온라인 정책 그래디언트라고 이 문제에서 자유로운 것은 아니다. 응답 전체에 점수 하나를 주고 토큰별로 나눠 싣는 순간, "합으로 볼 것인가 평균으로 볼 것인가"가 다시 나타난다. GRPO의 목적함수에 숨은 1/∣oi∣1/|o_i|1/∣oi​∣ 나누기가 바로 그 선택이고, 그것이 만드는 길이 편향은 Ch18(Dr. GRPO)에서 다시 만난다.

고치는 두 가지 방향

접근 1: 평균으로 나누기 — SimPO

SimPO(Meng et al., 2024)는 보상을 토큰당 평균 로그확률로 바꾼다.

rSimPO(x,y)=β∣y∣∑t=1∣y∣log⁡πθ(yt∣x,y<t)r_\text{SimPO}(x, y) = \frac{\beta}{|y|} \sum_{t=1}^{|y|} \log \pi_\theta(y_t \mid x, y_{<t})rSimPO​(x,y)=∣y∣β​t=1∑∣y∣​logπθ​(yt​∣x,y<t​)
  • 길이가 잣대에서 사라진다.
  • 레퍼런스 모델이 없다 — 메모리 절약. 대신 "최소 이만큼은 벌려라"는 목표 마진 γ\gammaγ 를 둔다. L=−log⁡σ(rw−rl−γ)\mathcal{L} = -\log\sigma(r_w - r_l - \gamma)L=−logσ(rw​−rl​−γ).
  • 추론 때 모델이 실제로 쓰는 양(토큰당 가능도)과 학습 보상이 일치한다. 자세한 뜻은 Ch13.

ORPO(Hong et al., 2024)도 출발은 평균이다. 토큰당 평균 로그확률을 다시 확률로 되돌린 값 Pˉθ(y∣x)=exp⁡(1∣y∣∑tlog⁡πθ(yt∣⋅))\bar{P}_\theta(y \mid x) = \exp\big(\frac{1}{|y|}\sum_t \log \pi_\theta(y_t \mid \cdot)\big)Pˉθ​(y∣x)=exp(∣y∣1​∑t​logπθ​(yt​∣⋅)) — 토큰 확률의 기하평균 — 을 쓰고, 여기에 오즈를 씌운다.

문제 4 — (킬러) 레퍼런스는 길이 편향을 막는가

선호 응답은 평균 40토큰, 비선호 응답은 평균 10토큰인 데이터로 DPO(β=0.1\beta = 0.1β=0.1)를 학습한다. 학습이 선호 응답의 모든 토큰에서 로그 비율을 +0.05+0.05+0.05씩, 비선호 응답의 모든 토큰에서 −0.05-0.05−0.05씩 바꿨다고 하자. (가) 학습 전 두 응답의 암묵적 보상은? (나) 학습 후의 보상 마진은? 선호 응답도 10토큰이었다면? (다) 이 데이터로 학습한 모델의 응답 길이는 어떻게 변할 것이며, 어떻게 막을 수 있는가?
