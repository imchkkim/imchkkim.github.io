놀라움과 정보

KL ≥ 0: 볼록함수 하나에서 나오는 부등식

“H(p, q) = H(p) + KL(p‖q)라면, KL이 음수가 되어 모델 q가 현실 p 자신보다 싸게 인코딩할(결과를 더 짧은 0·1 코드로 적을) 수도 있을까?”

KL이 늘 0 이상이고, 0이면 두 분포가 같다는 것을 지금 증명한다.

한 줄 증명

−log는 아래로 볼록한 함수라서, 곡선 위 두 점을 이은 선분은 늘 곡선보다 위에 있다. 점이 여럿이어도 같아서, 곡선 위 점들에 무게를 주고 무게중심을 잡으면 그 무게중심은 곡선보다 위에 있다. 이 사실을 젠센 부등식이라 부르고, 아래 증명은 이 그림 하나만 쓴다.

점들의 가로 좌표를 qi/pi, 무게를 pi로 잡는다.

KL(p ∥ q)=∑ipi(−log⁡qipi)≥−log⁡∑ipiqipi=−log⁡∑iqi≥−log⁡1=0\begin{aligned} \textcolor{#c2398a}{\mathrm{KL}}(\textcolor{#d6479f}{p}\,\|\,\textcolor{#7f8f10}{q}) &= \sum_i \textcolor{#d6479f}{p}_i \left(-\log \frac{\textcolor{#7f8f10}{q}_i}{\textcolor{#d6479f}{p}_i}\right) \\ &\ge -\log \sum_i \textcolor{#d6479f}{p}_i \frac{\textcolor{#7f8f10}{q}_i}{\textcolor{#d6479f}{p}_i} = -\log \sum_i \textcolor{#7f8f10}{q}_i \\ &\ge -\log 1 = 0 \end{aligned} KL(p∥q)​=i∑​pi​(−logpi​qi​​)≥−logi∑​pi​pi​qi​​=−logi∑​qi​≥−log1=0​

왼쪽은 곡선 위 점들의 무게중심 높이이고, 오른쪽 −log Σqi는 무게중심의 가로 좌표에서 잰 곡선의 높이다. 합은 pi > 0인 결과만 도니 Σqi ≤ 1이고, −log는 감소함수라 마지막 부등식이 나온다.

등호는 언제인가. 첫 부등식은 모든 점이 한 자리에 모일 때, 다시 말해 qi/pi가 모두 같을 때만 등호이고, 둘째 부등식은 Σqi = 1일 때 등호다. 둘을 합치면 q = p. KL = 0이면 두 분포가 같다.

H(p, q) ≥ H(p)도 따라 나오는데, 이 부등식 H(p, q) ≥ H(p)를 깁스 부등식이라 부른다. 현실의 빈도 p에 맞춘 코드표보다 싸게 인코딩하는 방법은 없다는 뜻이다.

파이썬

import numpy as np

p = np.array([0.5, 0.3, 0.2]); q = np.array([0.25, 0.25, 0.5])
x = q / p                                          # 곡선 위 점들의 가로 좌표
print("점의 x 좌표 q/p:", np.round(x, 3), "  p로 낸 무게중심 x:", round(np.sum(p * x), 10))
print("무게중심 높이 Σ p·(-log x) =", round(np.sum(p * -np.log(x)), 4), "= KL(p‖q)")

rng = np.random.default_rng(1)
P = rng.dirichlet(np.ones(5), 100_000)
Q = rng.dirichlet(np.ones(5), 100_000)
KL = np.sum(P * np.log(P / Q), axis=1)
print(f"무작위 10만 쌍에서 KL 의 최솟값 {KL.min():.4f}")
# 점의 x 좌표 q/p: [0.5   0.833 2.5  ]   p로 낸 무게중심 x: 1.0
# 무게중심 높이 Σ p·(-log x) = 0.218 = KL(p‖q)
# 무작위 10만 쌍에서 KL 의 최솟값 0.0007

무게중심의 가로 좌표는 늘 정확히 1이고, 가로 좌표 1에서 곡선 높이는 −log 1 = 0이다. KL은 무게중심이 곡선보다 얼마나 높이 떠 있는지다.

f-발산: 볼록함수 하나에 발산 하나

“KL ≥ 0의 증명에 쓴 것이 −log가 볼록하다는 것뿐이었다면, 다른 볼록함수로도 같은 증명이 되지 않을까?”

KL 발산 하나만으로 충분하지 않을까? KL에는 현실에서 일어나는 결과에 모델 q가 0을 주면 무한대가 된다는 약점이 하나 있고, 생성 모델을 학습시킬 때 이 약점이 실제로 걸린다. 원래의 GAN(생성적 적대 신경망, 2014)은 판별자와 겨루는 목적함수가 KL 대신 젠센–섀넌 발산을 줄이도록 짜여 있었다. 젠센–섀넌 발산은 무한대가 되지는 않지만, 두 분포가 전혀 겹치지 않으면 얼마나 떨어져 있든 늘 log 2로 같다. 2017년의 Wasserstein GAN 논문은 한 직선 위에 고르게 퍼진 분포와 그것을 옆으로 θ만큼 옮긴 분포를 예로 들었다. θ가 0이 아니면 KL은 무한대, 젠센–섀넌 발산은 log 2로 한결같아서, θ를 어느 쪽으로 얼마나 줄여야 하는지 알려 주지 못한다. 그래서 이 논문은 흙더미를 옮기는 비용으로 재는 바서슈타인 거리를 썼는데, 이 예에서 바서슈타인 거리는 |θ|로 θ가 줄어드는 만큼 줄어든다. 두 분포의 차이를 무엇으로 재느냐(KL, 젠센–섀넌 발산, 바서슈타인 거리)에 따라 학습이 무엇에 민감해지는지가 달라진다. 스코어 매칭이 줄이는 피셔 발산도 두 분포의 차이를 재는 또 하나의 척도다.

KL의 증명을 그대로 일반화한 가족이 있다.

Df(p ∥ q)=∑iqi f ⁣(piqi)\textcolor{#c2398a}{D}_{\textcolor{#5b6fe0}{f}}(\textcolor{#d6479f}{p}\,\|\,\textcolor{#7f8f10}{q}) = \sum_i \textcolor{#7f8f10}{q}_i\, \textcolor{#5b6fe0}{f}\!\left(\frac{\textcolor{#d6479f}{p}_i}{\textcolor{#7f8f10}{q}_i}\right) Df​(p∥q)=i∑​qi​f(qi​pi​​)
Dff-발산f발산을 정하는 볼록함수, f(1)=0pi, qi현실과 모델의 확률i결과의 번호\begin{array}{ll} \textcolor{#c2398a}{D}_{\textcolor{#5b6fe0}{f}} & f\text{-발산} \\ \textcolor{#5b6fe0}{f} & \text{발산을 정하는 볼록함수, } f(1) = 0 \\ \textcolor{#d6479f}{p}_i,\ \textcolor{#7f8f10}{q}_i & \text{현실과 모델의 확률} \\ i & \text{결과의 번호} \end{array} Df​fpi​, qi​i​f-발산발산을 정하는 볼록함수, f(1)=0현실과 모델의 확률결과의 번호​

증명은 KL 때와 같다. f가 볼록이니 무게 qi로 낸 무게중심이 곡선 위에 있고, Df ≥ f(Σ qi · pi/qi) = f(1) = 0이다.

f(x) = x log x를 넣으면 KL(p‖q)가 나오고, f(x) = −log x를 넣으면 방향이 뒤집힌 KL(q‖p)가 나온다. f(x) = (x − 1)²를 넣으면 카이제곱 발산 χ²(카이제곱) = Σ(pi − qi)²/qi가 나온다. 젠센–섀넌 발산과 헬링거 거리도 이 가족이지만, 바서슈타인 거리와 피셔 발산은 이 가족이 아니다. 두 분포의 차이를 재는 척도는 f-발산보다 더 많다.

비유: 망치와 공구함

−log는 못(KL ≥ 0의 증명)을 잘 박는 좋은 망치다. f-발산은 망치 자루에 해당하는 볼록성은 그대로 두고 머리(볼록함수 f)만 바꿔 끼우는 공구 세트다.

파이썬

import numpy as np

p = np.array([0.5, 0.3, 0.2])
q = np.array([0.25, 0.25, 0.5])

def D_f(f, p, q):                       # D_f(p‖q) = Σ q f(p/q)
    return np.sum(q * f(p / q))

fs = {
    "KL      f(x)=x log x":      lambda x: x * np.log(x),
    "역방향KL f(x)=-log x":       lambda x: -np.log(x),
    "χ²      f(x)=(x-1)²":       lambda x: (x - 1)**2,
    "헬링거² f(x)=(√x-1)²":       lambda x: (np.sqrt(x) - 1)**2,
}
for name, f in fs.items():
    print(f"{name}  D_f = {D_f(f, p, q):.4f}")
print(f"확인: KL(p‖q)={np.sum(p*np.log(p/q)):.4f}  KL(q‖p)={np.sum(q*np.log(q/p)):.4f}  Σ(p-q)²/q={np.sum((p-q)**2/q):.4f}")
# KL      f(x)=x log x  D_f = 0.2180
# 역방향KL f(x)=-log x  D_f = 0.2393
# χ²      f(x)=(x-1)²  D_f = 0.4400
# 헬링거² f(x)=(√x-1)²  D_f = 0.1127
# 확인: KL(p‖q)=0.2180  KL(q‖p)=0.2393  Σ(p-q)²/q=0.4400

볼록함수마다 발산이 하나씩 태어나고, 모두 0 이상이다.

이 절의 결론

“KL ≥ 0은 −log가 볼록하다는 사실 하나에서 나온다.”

“−log는 강력하지만 하나의 사례일 뿐이다. 볼록함수의 세계 전체를 열면 더 많은 것이 보인다.”

문제 10. 50% 오르고 50% 내린 주식

어떤 주식이 첫해에 50% 오르고 다음 해에 50% 내렸다. (가) 두 해 수익률의 평균은 몇 %이고, 원금 100만 원은 실제로 얼마가 되는가? (나) 한 해마다 곱해진 배수 x₁ = 1.5, x₂ = 0.5에 대해, −log x의 평균과 배수의 평균에서 잰 −log를 견주어라. 어느 쪽이 크고, 차이는 얼마인가(nat)?

함께 풀기

수익률의 평균은 (+50% − 50%)/2 = 0%예요. 원금은 150만 원이 됐다가 그 반이니까 75만 원이고요.

평균 0%라는 숫자만 보면 본전 같은데 25만 원이 없어졌네. 수익률은 더해지는 게 아니라 배수로 곱해지니까, 수익률을 산술평균하면 실제 원금과 안 맞는 거구나.

(나)는 −ln 1.5 ≈ −0.405, −ln 0.5 ≈ 0.693이라 평균이 0.144, 배수의 평균 (1.5 + 0.5)/2 = 1에서 잰 −ln은 0. −log의 평균이 0.144만큼 커요.

무게 ½, ½에 가로 좌표 1.5와 0.5, 무게중심의 가로 좌표는 1. 어디서 본 그림이죠?

KL 증명 그림이요. 가로 좌표 qi/pi의 무게중심이 늘 1이었죠.

그러면 p와 q를 어떻게 잡아야 그 그림이 이 주식이 될까요?

무게가 ½, ½니까 p = (½, ½)요. 가로 좌표가 배수 xi가 되려면… qi = pixi로 두면 되겠네요. q = (0.75, 0.25)예요.

그럼 그 KL(p‖q)가 아까 0.144야?

응, 같은 그림이니까 바로 그 0.144야.

0.144는 해마다 곱해진 배수가 고르지 않아서 줄어든 한 해 평균 로그 수익률이네요. 두 해 모두 배수가 1이었으면 0이고요.

문제 11. 등호가 늘 서는 발산

f(x) = x − 1도 볼록함수이고 f(1) = 0이다. (가) 이 f로 만든 Df(p‖q)를 위 파이썬의 p = (0.5, 0.3, 0.2), q = (0.25, 0.25, 0.5)로 계산하라. (나) KL에서는 「발산이 0이면 두 분포가 같다」가 성립했다. 이 f에서도 성립하는가? 성립하지 않는다면, 한 줄 증명의 등호 조건에는 볼록성 말고 무엇이 더 쓰였는가?

함께 풀기

코드로 돌렸더니 0이 나왔어요. 다른 p, q를 넣어도 다 0이에요. 발산이 0이니까 p = q여야 하는데 둘은 분명히 다르잖아요. 제 코드가 틀렸나 봐요.

코드는 맞아. Σ qi(pi/qi − 1) = Σ pi − Σ qi = 1 − 1 = 0이니까 늘 0이야. 문제는 f 쪽이지. x − 1은 직선이니까 볼록함수가 아니잖아.

볼록의 정의가 뭐였죠? 곡선 위 두 점을 이은 선분이…

…곡선보다 아래로 내려가지 않는다. 직선이면 선분이 곡선과 겹치니까 볼록이 맞네요. 아래로 내려가지 않는다는 거지, 늘 위에 떠 있다는 게 아니었어요.

그럼 KL의 한 줄 증명에서 「모든 점이 한 자리에 모일 때만 등호」는 −log의 어떤 성질에서 나왔어요?

점들이 흩어져 있으면 무게중심이 곡선보다 떠 있어야 해요. 그러려면… 곡선이 어디서나 휘어 있어야 하네요.

x − 1에서는 어때요?

곧은 선이라 점들이 흩어져 있어도 무게중심이 선 위에 그대로 있어요. 두 점을 이은 선분이 곡선과 양 끝에서만 만나는 성질, 엄격하게 볼록하다고 하죠. −log는 엄격하게 볼록이라 KL = 0이면 p = q까지 나오는데, x − 1은 곧기만 해서 아무것도 가려내지 못해요.

f-발산의 조건에 「볼록, f(1) = 0」만 적어 두면 늘 0 이상이긴 하지만, 두 분포를 가려내는 자가 되려면 조건이 하나 더 필요하네요. 「0 이상」만 확인하고 「0이면 같다」를 안 따졌으면 이런 쓸모없는 자를 통과시킬 뻔했어요.

볼록과 엄격한 볼록을 왜 굳이 따로 정의하나 했는데, 등호 조건 때문이었어요.

문제 12. 엔트로피보다 낮은 훈련 loss

결과가 셋인 현실 분포 p = (0.5, 0.3, 0.2)에서 샘플 10개를 뽑았더니 결과 1, 2, 3이 6, 3, 1번 나왔다. 모델이 이 샘플을 그대로 외워 경험분포 p̂ = (0.6, 0.3, 0.1)을 내놓는다. (가) 이 모델의 훈련 loss(샘플 10개에서 낸 평균 음의 로그우도, nat)를 구하고, 현실의 엔트로피 H(p)와 비교하라. (나) 새로 뽑은 샘플이 충분히 많을 때 그 샘플에서의 평균 loss는 얼마인가? (다) 현실과 똑같은 모델 q = p라면 같은 10개에서의 훈련 loss는 얼마인가? (라) (가)는 「크로스 엔트로피는 엔트로피보다 작아질 수 없다」와 부딪히는가?

함께 풀기

훈련 loss는 −(0.6 ln 0.6 + 0.3 ln 0.3 + 0.1 ln 0.1) ≈ 0.898 nat이에요. 현실의 엔트로피는 1.030이고요. 엔트로피 아래로 내려갔어요! 이 모델이 현실보다 더 잘 아는 거예요.

새 샘플에서는요?

새 샘플은 p에서 나오니까 −(0.5 ln 0.6 + 0.3 ln 0.3 + 0.2 ln 0.1) ≈ 1.077. 어, 1.030보다 높아졌네요.

1.077 − 1.030 = 0.047이 KL(p‖p̂)이니까 깁스 부등식이 말하는 대로야. 이상한 건 (가)지. 크로스 엔트로피는 엔트로피보다 작아질 수 없다고 증명했는데.

한 줄 증명에서 무게로 쓴 분포와, 비교한 엔트로피의 분포는 무엇이었죠? 훈련 loss에서는요?

증명은 H(p, q) ≥ H(p)였어요. 무게도 p, 비교 대상도 p요.

훈련 loss에서는 무엇으로 무게를 달았어요?

샘플에서 센 경험분포 p̂요. 그러면 H(p̂, q)니까, 이 증명이 말해 주는 하한은 H(p̂) = 0.898이에요. 현실의 H(p)가 아니고요.

그럼 (가)는 그 하한 H(p̂)에 닿은 거네. 부딪히는 게 아니고.

(다)도 해 봐요. 현실과 똑같은 모델 q = p는 훈련 loss가 얼마죠?

−(0.6 ln 0.5 + 0.3 ln 0.3 + 0.1 ln 0.2) ≈ 0.938. 외운 모델의 0.898보다 나빠요! 훈련 loss만 보면 현실과 똑같은 모델이 외운 모델에게 져요.

그래요. 훈련 loss의 하한은 훈련 샘플의 경험분포가 정해요(H(p̂)). 현실까지 얼마나 먼지는 새 샘플에서 잰 loss, 곧 H(p) + KL(p‖q)가 알려 주고요.

그래서 검증 세트를 따로 두는 거네요. 연습문제를 답까지 외운 친구가 연습 점수는 만점인데 시험에서 무너지는 거랑 같아요.

통계 시간에 표본평균을 같은 샘플에 다시 써서 분산을 재면 실제보다 작게 나온다고 배웠는데, 샘플에 맞춘 값으로 같은 샘플을 재면 늘 좋게 나온다는 점에서 두 경우가 같네요.

정리 연습문제

물음. 공정한 동전을 던져 10번 연속 앞면이 나왔다. 10번 연속 앞면의 놀라움은 몇 bit인가?

  • [x] 10 bit 〔맞음: 서로 독립인 사건의 확률은 곱해지고 놀라움은 더해진다. 한 번에 1 bit씩 열 번이다.〕
  • [ ] 1 bit. 동전 하나를 던진 결과니까 〔틀림: 1 bit는 한 번 던지기의 놀라움이다. 열 번 모두 앞면일 확률은 1,024분의 1이다.〕
  • [ ] 1,024 bit 〔틀림: 1,024는 확률의 역수다. 놀라움은 1,024에 밑이 2인 로그를 씌운 값이라 10이다.〕

물음. 언어 모델이 「나는」「밥을」「먹었다」에 앞 토큰을 알고 각각 0.2, 0.5, 0.9를 주었다. 문장 전체의 놀라움은?

  • [ ] 세 토큰이 서로 독립이 아니라서 토큰마다의 놀라움을 더할 수 없다 〔틀림: 앞 토큰을 알고 준 확률로 재면 독립이 아니어도 놀라움이 그대로 더해진다.〕
  • [x] 토큰마다의 놀라움을 더한 값과 같다 〔맞음: 문장의 확률은 앞을 알고 준 확률들의 곱이고, 로그를 씌우면 곱이 합이 된다.〕
  • [ ] 토큰마다의 놀라움을 더한 값보다 크다 〔틀림: 두 값은 정확히 같다. 놀라움이 부풀려지는 것은 앞을 모르는 확률로 재서 더할 때다.〕

물음. 공정한 12면체 주사위의 엔트로피를 numpy의 np.log로 계산했더니 2.485가 나왔다. 맞는 읽기는?

  • [ ] 2.485 bit 〔틀림: np.log는 자연로그라서 단위는 nat이다.〕
  • [x] 2.485 nat이고, ln 2로 나누면 약 3.585 bit 〔맞음: 1 nat이 약 1.443 bit라서 bit로 적은 숫자가 늘 더 크다. 반씩 가르는 질문으로 따져도 3번과 4번 사이다.〕
  • [ ] 2.485 nat이고, ln 2를 곱하면 약 1.72 bit 〔틀림: 반씩 가르는 질문 세 번으로는 여덟 개밖에 못 가른다. 열두 개를 가르려면 3 bit보다 커야 한다.〕

물음. 실제로 (½, ¼, ⅛, ⅛)의 비율로 나오는 네 말로 약어 코드표를 만든다. 자릿수를 괜히 더 많이 쓰게 되는 쪽은?

  • [ ] 네 말을 고르게 믿고 만든 코드표. 아무것도 모르니까 〔틀림: 고르게 믿으면 한 말에 0.25 bit를 더 쓰고, 거꾸로 믿으면 0.875 bit를 더 쓴다.〕
  • [x] 비율을 거꾸로 (⅛, ⅛, ¼, ½)로 믿고 만든 코드표 〔맞음: 가장 흔한 말에 가장 긴 코드를 주어 평균 자릿수가 크게 늘었다. 모르는 것보다 틀리게 아는 것이 더 비싸다.〕
  • [ ] 같다. 둘 다 실제 비율과 다르게 믿었다 〔틀림: 코드 길이는 믿은 비율이 정하고 평균은 실제 비율로 낸다. 얼마나 다르게 믿었는지에 따라 손해가 다르다.〕

물음. 똑같은 입력에 평가자 라벨이 70%는 「1」, 30%는 「0」으로 엇갈린다. 모델을 아무리 키워도 이 입력의 평균 크로스 엔트로피 loss는?

  • [ ] 「1」일 확률로 1을 내면 0까지 내려간다 〔틀림: 라벨이 「0」인 30%에서 놀라움이 끝없이 커진다.〕
  • [x] 라벨 분포의 엔트로피 아래로 내려가지 않는다. 가장 작은 곳은 「1」일 확률로 0.7을 낼 때다 〔맞음: loss는 라벨 분포의 엔트로피와 발산의 합이고, 모델이 줄일 수 있는 것은 발산뿐이다.〕
  • [ ] 「1」일 확률로 0.99를 내면 거의 0이 된다 〔틀림: 0.99를 내면 오히려 약 1.39 nat으로 커진다. 「0」 라벨에서 크게 놀라기 때문이다.〕

물음. 샘플 10개를 그대로 외운 모델의 훈련 loss가 현실 분포의 엔트로피보다 낮게 나왔다. 어떻게 읽어야 하나?

  • [ ] 모델이 현실보다 더 잘 안다 〔틀림: 새로 뽑은 샘플에서 재면 loss가 현실의 엔트로피보다 높다.〕
  • [ ] 크로스 엔트로피가 엔트로피보다 작을 수 없다는 부등식이 깨졌다 〔틀림: 훈련 loss는 샘플에서 센 경험분포로 무게를 단다. 그 하한은 경험분포의 엔트로피이고, 외운 모델은 그 하한에 닿았을 뿐이다.〕
  • [x] 훈련 loss의 하한은 훈련 샘플의 경험분포가 정하고, 현실과 얼마나 다른지는 새 샘플에서 잰다 〔맞음: 같은 샘플로 재면 그 샘플에 맞춘 모델이 늘 좋게 나온다. 그래서 검증 세트를 따로 둔다.〕
