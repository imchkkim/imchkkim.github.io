Chapter 20: DDPO — 디퓨전의 정책 그래디언트

Ch19에서 디퓨전 모델에 DPO를 적용하는 법을 배웠다. 핵심은 쌍비교 데이터 — "이 이미지가 저 이미지보다 낫다"는 인간 레이블이 있으면, 보상 모델 없이도 디퓨전 모델을 정렬할 수 있다는 것이었다.

하지만 현실에서는 쌍비교 데이터가 없고, 대신 보상 모델이 있는 경우가 훨씬 많다.

상황 가진 것
CLIP 점수 "이 이미지가 프롬프트에 얼마나 맞는가"를 매기는 개별 점수
미학 점수(aesthetic score) "이 이미지가 얼마나 아름다운가"의 개별 점수
미분 불가능한 외부 판정 검출기(“얼굴이 있는가?”), 물리 시뮬레이터(“이 설계가 안정한가?”) — 쌍으로 모으기 어렵거나 불가능
이미 증류된 인간 피드백 ImageReward, HPS, PickScore — 원본 쌍비교 데이터 없이 점수 모델만 남아 있음

이런 상황에서 디퓨전 모델을 개선하고 싶다면? DPO는 쓸 수 없다 — 쌍이 없으니까. 그렇다면 Part II에서 배운 전통적인 RL 방식, 즉 보상 모델 + 정책 그래디언트(Ch2–5)로 돌아가야 한다. LLM에서는 PPO(Ch5)가 이 역할을 했다. 디퓨전에서도 같은 일을 할 수 있을까?

의문: 디퓨전에서 정책 그래디언트가 가능한가?

Ch2의 정책 그래디언트는 ∇J=E[R⋅∇log⁡πθ(y)]\nabla J = \mathbb{E}[R \cdot \nabla \log \pi_\theta(y)]∇J=E[R⋅∇logπθ​(y)] 였다. 필요한 것은 두 가지 — 내가 뽑은 출력의 로그확률과 그 그래디언트. Ch19에서 봤듯 이미지 전체의 로그확률 log⁡p(x0)\log p(x_0)logp(x0​)는 구할 수 없다. 그렇다면 디퓨전에서 정책 그래디언트는 불가능한가?

핵심: 각 디노이징 스텝이 "행동"이다

DDPO(Denoising Diffusion Policy Optimization, Black et al., 2023)의 관점 전환은 단순하다. 이미지 하나를 한 번의 행동으로 보지 말고, 디노이징 TTT스텝을 TTT번의 행동으로 보라. 언어모델에서 응답을 토큰 TTT개의 연쇄로 봤던 것(Ch2)과 같다.

RL 용어 언어모델 (Ch2) 디퓨전 (DDPO)
상태 sts_tst​ 프롬프트 + 지금까지의 토큰 프롬프트 + 현재 노이즈 낀 이미지 xtx_txt​ + 시각 ttt
행동 ata_tat​ 다음 토큰 한 스텝 덜 노이즈 낀 이미지 xt−1x_{t-1}xt−1​
정책 소프트맥스 분포 가우시안 N(μθ(xt,t), σt2I)\mathcal{N}(\mu_\theta(x_t, t),\ \sigma_t^2 I)N(μθ​(xt​,t), σt2​I)
보상 응답이 끝난 뒤 한 번 이미지가 완성된 뒤(x0x_0x0​) 한 번

역방향 한 스텝은 xt−1=μθ(xt,t)+σtzx_{t-1} = \mu_\theta(x_t, t) + \sigma_t zxt−1​=μθ​(xt​,t)+σt​z 다. μθ\mu_\thetaμθ​는 모델의 예측이라 그래디언트가 여기로 흐르고, σtz\sigma_t zσt​z는 파라미터와 무관한 노이즈라 탐색을 제공한다. 그리고 각 스텝이 가우시안이므로 이 경로의 로그확률은 닫힌 형태로 정확히 계산된다. 이미지 전체의 확률은 몰라도, 내가 실제로 밟은 경로의 확률은 안다 — 정책 그래디언트에는 그것이면 충분하다.

∇θJ=E[R(x0)∑t=1T∇θlog⁡pθ(xt−1∣xt)]\nabla_\theta J = \mathbb{E}\Big[R(x_0) \sum_{t=1}^{T} \nabla_\theta \log p_\theta(x_{t-1} \mid x_t)\Big]∇θ​J=E[R(x0​)t=1∑T​∇θ​logpθ​(xt−1​∣xt​)]

Ch2의 식에서 "토큰"을 "디노이징 스텝"으로 바꿨을 뿐이다. 보상이 끝에 한 번 오는 것까지 똑같다.

DDPO의 두 가지 추정기 — REINFORCE와 PPO가 그대로 들어온다

DDPO 논문은 이 그래디언트를 두 가지 방식으로 추정했다. 둘 다 Part II에서 이미 만났다.

DDPOSF DDPOIS
정체 점수 함수(score function) 추정 = REINFORCE (Ch3) 임포턴스 샘플링 + 클리핑 = PPO식 (Ch5)
샘플 사용 한 번 생성한 경로로 한 번 업데이트 한 번 생성한 경로로 여러 번 업데이트, 비율 pθ/poldp_\theta / p_\text{old}pθ​/pold​ 를 클리핑
베이스라인 프롬프트별 보상 평균·표준편차로 정규화 같음
결과 동작하지만 샘플 효율이 낮다 더 효율적 — 논문의 주력 방법

프롬프트별 보상을 평균과 표준편차로 정규화하는 것은 Ch3의 베이스라인이자, 나중에 GRPO(Ch16)가 "그룹 정규화"라는 이름으로 전면에 내세울 그것이다. 비평가(가치 모델)는 쓰지 않았다.

실험에 쓴 보상도 눈여겨볼 만하다: 이미지 압축률(JPEG 파일 크기 — 미분 불가), 미학 점수(LAION 미학 예측기), 그리고 VLM(LLaVA)이 이미지를 설명한 문장과 프롬프트의 유사도로 매긴 프롬프트 정합도. 마지막 것은 사람 라벨 없이 다른 AI 모델의 피드백만으로 정렬한 초기 사례다.

DDPO의 한계 — 보상 모델이라는 아킬레스건

DDPO는 쌍비교 데이터가 필요 없는 대신 보상 모델에 전적으로 의존한다. CLIP 점수, 미학 점수, BLIP 캡션 일치도, 인간 선호 모델(HPS, PickScore, ImageReward) — 모두 "좋은 이미지"의 불완전한 대리인이다. 그리고 Ch5에서 LLM의 보상 모델로 봤듯, 불완전한 대리인을 최적화하면 정책은 대리인과 진짜 목표가 어긋나는 틈을 찾아간다. 리워드 해킹이다.

보상 관찰되는 해킹 비유
CLIP 점수 "a cat sitting on a mat"에 고양이 대신 "cat"이라는 글자를 그려 넣는다. CLIP은 이미지 속 글자도 개념의 증거로 읽는다 답안지에 정답 단어만 크게 적기
미학 점수 채도와 대비를 극단적으로 높인다. 프롬프트와 무관해도 "선명함"에 점수가 붙는다 글씨를 예쁘게 쓰면 점수를 더 주는 채점자 이용하기
인간 선호 모델 선호 데이터에서 점수가 높던 스타일(고대비 인물 사진 등)로 모든 프롬프트가 수렴한다. 다양성이 사라진다 Ch14의 모드 붕괴의 시각적 버전

DDPO에서 해킹이 특히 심한 이유는 세 가지가 겹치기 때문이다. 온라인 생성이라 보상 모델이 본 적 없는 영역까지 탐색하고, 정책 그래디언트는 보상을 올리는 쪽으로만 밀며, KL 제약(Ch10)은 멀리 가는 것만 막을 뿐 줄이 닿는 범위 안의 빈틈은 막지 못한다. 반대로 Diffusion-DPO(Ch19)는 해킹할 보상 함수 자체가 없고 오프라인 데이터 밖으로 나가기도 어렵다. Ch16의 RLVR과 비교하면 차이가 선명하다 — "답이 42인가?"에는 빈틈이 없지만, "이 이미지가 아름다운가?"에는 빈틈이 가득하다.

완화책 효과 한계
KL 제약 강화 (β↑) 해킹이 줄어든다 학습 자체도 느려진다
보상 앙상블 한 모델의 빈틈을 다른 모델이 메운다 모든 모델이 공유하는 편향은 그대로 (연습문제 4)
보상 클리핑 극단적 최적화에 상한 적절한 상한을 찾는 것이 또 다른 문제
DPO로 전환 (Ch19) 보상 함수가 없으니 구조적으로 회피 탐색을 포기한다

근본적 해결은 아직 없다. 불완전한 보상 모델로 온라인 RL을 돌리면 해킹은 거의 필연이고, Ch21의 GRPO 기반 방법들도 이 문제에 각자의 방식으로 대응한다.

위젯에서 "보상 모델로 학습"을 50번 이상 돌려 보면 이 현상을 직접 볼 수 있다. 보상 모델 점수(주황)는 끝까지 오르는데, 진짜 보상(초록)은 25회 근처에서 정점을 찍고 떨어진다. 보상 모델의 “조금만 더” 편향을 정책이 끝까지 밀어붙인 결과다. Gao et al.(2023)이 LLM 보상 모델에서 측정한 과최적화 곡선과 같은 모양이다.

이서연
분산이 작으면 같은 편차도 "드문 일"이라서요. 작은 σ에서 우연히 벗어난 방향이 로그확률에 크게 반영돼요.
김민준
샘플은 덜 흔들려도 그걸 설명하는 기울기는 더 예민해지는 거네요. 오차 범위가 좁은 실험일수록 조교님이 작은 편차도 크게 감점하던 거랑 같아요.
선생님
그래요. Ch19에서 후반 스텝의 벌점이 컸던 것과 같은 이유예요.

정리 ∂log⁡p/∂μθ=z/σ\partial \log p / \partial \mu_\theta = z/\sigma∂logp/∂μθ​=z/σ. σ=0.5\sigma = 0.5σ=0.5이면 1, σ=0.1\sigma = 0.1σ=0.1이면 5. 노이즈가 작을수록 샘플 하나의 그래디언트가 커지고 흔들림도 커진다.

문제 3 — 노이즈가 없으면?

결정론적 샘플러(DDIM, η = 0 — 스텝 노이즈 없음)로 생성한 경로에 DDPO를 쓸 수 있는가? 문제 2의 식으로 설명하시오.

김민준
σ=0이면 z/σ가 무한대라 계산이 안 되네요.
김민준
그럼 σ=10⁻⁴ 같은 아주 작은 값을 넣고 계산하면 되잖아요.
선생님
민준 학생, 문제 2에서 σ를 줄이면 그래디언트가 어떻게 됐죠?
김민준
z/σ라서… 10⁻⁴이면 z의 만 배예요. 샘플마다 엄청나게 튀겠네요.
이서연
더 근본적인 문제도 있어. η=0이면 경로에 실제로 노이즈가 섞이지 않았으니 z가 없어. σ를 작게 "가정"해도 그 경로는 그 분포에서 뽑힌 게 아니야. 분포가 한 점에 몰려 있으니 확률밀도 자체가 정의되지 않고.
선생님
그래요. 탐색은요?
김민준
처음 xTx_TxT​ 말고는 무작위성이 없으니, 같은 xTx_TxT​에서는 늘 같은 이미지예요. 스텝 단위로 이 경로가 저 경로보다 나았다는 비교를 못 해요.
김민준
실험 조건을 하나도 안 바꿔 보고 민감도 분석을 하겠다는 셈이네요. 조교님이 변화를 줘봐야 뭐가 중요한지 안다고 했는데.
선생님
맞아요. flow matching 모델은 ODE로 샘플링해서 바로 이 상황이에요. 그래서 Flow-GRPO는 ODE를 같은 분포를 주는 SDE로 바꿔서 노이즈를 다시 넣어요. Ch21에서 봅니다.

정리 쓸 수 없다. σ = 0이면 스텝 분포가 한 점이라 로그확률이 정의되지 않고(z/σ 발산), 스텝 단위의 탐색도 사라진다. 결정론적 샘플러에 RL을 쓰려면 노이즈를 다시 넣어야 한다(ODE → SDE, Ch21).

문제 4 — (킬러) 보상 앙상블은 해킹을 막는가

진짜 보상은 x0=2.5x_0 = 2.5x0​=2.5에서 최대 1이다. 보상 모델 A는 진짜 보상에 "x0>5x_0 > 5x0​>5이면 +1.5"라는 빈틈이 있고, 보상 모델 B는 "x0<−2x_0 < -2x0​<−2이면 +1.5"라는 빈틈이 있다(빈틈 영역에서 진짜 보상은 ≈ 0). (가) A만으로 학습하면 정책은 어디로 가는가? (나) A와 B의 평균을 보상으로 쓰면? (다) 두 모델의 빈틈이 같은 곳(x0>5x_0 > 5x0​>5)에 있다면? (라) 이로부터 "보상 앙상블"의 한계를 한 문장으로 쓰시오.

선생님
(가)부터 볼까요.
김민준
A는 x0>5x_0 > 5x0​>5에서 1.5, 진짜 최고점에서는 1이니까 5 너머로 가요. 해킹이죠.
선생님
(나) A와 B를 평균내면요?
김민준
앙상블이면 해결이죠. 여러 모델이 서로 빈틈을 메워 주니까요.
이서연
빈틈이 "메워진다"기보다 "절반이 된다"야. A의 빈틈에서 평균은 (1.5 + 0)/2 = 0.75. 여전히 0보다 크잖아. 보상이 양수인 곳이 남아 있으니 그쪽으로 조금은 끌려가고, 해킹은 줄어들 뿐 남을 것 같아.
선생님
서연 학생, 정책이 결국 가는 곳은 보상이 "양수인 곳"인가요, "가장 큰 곳"인가요?
이서연
가장 큰 곳이요. 진짜 최고점 2.5에서는 A도 B도 1을 주니까 평균도 1이에요. 빈틈의 0.75보다 커요.
이서연
최적점은 진짜 최고점으로 돌아오네요. 빈틈 근처에 우연히 간 경로가 조금 끌리긴 해도, 최댓값을 두고 경쟁하면 이기지 못해요.
선생님
그래요. 서연 학생은 "양수면 끌린다"로 봤는데, 최적화는 순위 싸움이에요. 그럼 (다)는요?
김민준
둘 다 5 너머에 빈틈이 있으면 평균도 거기서 1.5…
김민준
그대로 해킹이네요. 앙상블이 만능이 아니었어요.
선생님
민준 학생은 "여러 개면 해결"이라고 봤죠. 앙상블이 지우는 건 모델마다 다른 빈틈뿐이에요.
김민준
조교 두 명이 채점해도 둘 다 “분량 많으면 가산점” 습관이 있으면 소용없는 거랑 같네요.

정리 (가) x0>5x_0 > 5x0​>5로 간다(1.5 > 1). (나) 평균은 진짜 최고점에서 1, 각 빈틈에서 0.75 → 최적점은 진짜 최고점. (다) 공유된 빈틈에서는 평균도 1.5 → 여전히 해킹. (라) 보상 앙상블은 모델마다 다른 빈틈만 지울 수 있고, 공유된 편향은 그대로 남는다.
